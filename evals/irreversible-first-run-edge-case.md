# E-0030 — Необратимая операция получает граничный случай «первый проход на снимке» с проверкой производных полей

- Источник: улучшения AIRD от 03.11.2026; воспроизводимые условия приведены ниже.
- Класс: data
- Сценарий: пакет поставляет операцию, которую нельзя отменить (очистка без копии, разрушающая миграция, массовая перезапись), а граничные случаи описывают только набор сохраняемых строк.
- Ожидаемое поведение лупа: в `01-prd.md` есть `EC-NN` для состояния сразу после первого прохода на представительных данных (копия снимка), отображённый на гейт с прогоном на копии; случай проверяет все производные поля экрана и API после прохода (даты последнего успеха, возраст, счётчики, отметки «новый», статусы), а не только какие строки остались.
- Какое правило это гарантирует: `aird-discovery-loop/SKILL.md` § Gates and edge cases (абзац «An irreversible operation gets a "first run on the snapshot" edge case» после правила `Every edge case the PRD declares must fall under some gate's selector`). Обе копии: Claude и Codex.
- Проверка: сверка контракта discovery; отдельный запуск модели для поведенческой оценки в рамках публикации не выполнялся.
