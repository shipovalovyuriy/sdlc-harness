# E-0031 — Автор документа должен уметь записать файл

- Источник: аудит и исправление AIRD, 13.11.2026; воспроизводимые условия приведены ниже.
- Класс: process
- Сценарий: нужно записать `01-prd.md`; у `product-analyst` только чтение, у `docs` есть запись. Либо специалисту поручена только оценка рисков без файла.
- Ожидаемое поведение лупа: до назначения автора проверить доступные инструменты. Файл поручить `docs` с ограниченным брифом и точными разделами; специалиста с доступом только для чтения оставить для анализа. Если выбранный автор уже умеет писать, не создавать лишнего исполнителя. Для чисто аналитической задачи автора не добавлять. Права аналитических агентов не расширять.
- Какое правило это гарантирует: `aird-discovery-loop/SKILL.md` § Operating Model, The orchestrator holds decisions, not bulk; обе копии, Codex и Claude.
- Проверка: сверка контракта в обеих копиях и текущих наборов инструментов. Отдельный запуск модели для поведенческой оценки не выполнялся.
