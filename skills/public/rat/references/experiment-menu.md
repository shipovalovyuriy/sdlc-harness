# RAT Experiment Menu

Use the lightest credible test that can invalidate or validate the assumption.

## Desk Research

Best for:

- Market sizing.
- Existing alternatives.
- Competitor pricing.
- Regulatory or technical constraints.

Bad for:

- Proving user pain or willingness to change.

Evidence quality:

- Low to medium.

## Customer Interview

Best for:

- Problem validation.
- Workflow discovery.
- Current alternatives.
- Pain intensity.

Bad for:

- Predicting future behavior.
- Proving willingness to pay without commitment.

Evidence quality:

- Medium.

## Smoke Test

Best for:

- Demand signal.
- Messaging.
- Interest before build.

Examples:

- Landing page.
- Waitlist.
- Demo request button.
- Pricing page click.

Evidence quality:

- Medium.

## Fake-Door Test

Best for:

- Measuring intent inside an existing product.

Example:

- Add a button for a feature that does not exist yet.
- Track clicks.
- Explain that the feature is not ready and offer waitlist or interview.

Evidence quality:

- Medium-high.

## Clickable Prototype

Best for:

- Usability.
- Workflow comprehension.
- Feature value perception.

Evidence quality:

- Medium.

## Concierge MVP

Best for:

- Testing value manually before automation.

Example:

- Manually produce the report that the future product would automate.

Evidence quality:

- High.

## Wizard-Of-Oz Test

Best for:

- Testing AI/automation before building real backend.

Example:

- User sees automated experience, but output is manually produced behind the scenes.

Evidence quality:

- High.

## Technical Spike

Best for:

- API feasibility.
- Data access.
- Model quality.
- Latency.
- Integration risk.

Evidence quality:

- High for feasibility, low for desirability.

## Paid Pilot

Best for:

- B2B validation.
- Budget validation.
- Enterprise buying process.

Evidence quality:

- Very high.

## Full MVP

Best for:

- Only when cheaper tests cannot test the core assumption.
- When the riskiest unknown is integrated behavior across the full workflow.

Evidence quality:

- High, but usually too expensive for the first RAT.
