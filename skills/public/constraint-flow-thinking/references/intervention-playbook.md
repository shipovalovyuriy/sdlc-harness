# Intervention Playbook

Choose the smallest intervention that changes global throughput through the constraint.

## WIP Limit

Use when too much work is started and little is finished. Limit active items per person/team/stage.

## Reduce Inflow

Use when new work enters faster than the constraint can process it. Pause intake, add triage, or kill low-value work.

## Increase Outflow

Use when the constraint can be sped up safely. Add review capacity, simplify handoffs, remove blockers, improve tooling.

## Protect Constraint

Use when the constraint is constantly interrupted. Shield critical people/stages from low-value work.

## Remove Rework Loop

Use when items repeatedly return. Improve ready criteria, acceptance criteria, tests, design review, or feedback timing.

## Shorten Feedback Loop

Use when late feedback creates large batches and rework. Add faster tests, previews, user checks, deploy signals, or decision checkpoints.

## Clarify Decision Rights

Use when work waits for approval. Name decision owner, input providers, deadline, and escalation path.

## Automate Repetitive Checks

Use when manual validation consumes the constraint. Automate linting, tests, policy checks, formatting, report generation, or routing.

## Reduce Batch Size

Use when large work items slow review, QA, deployment, or decisions. Split work into independently valuable increments.

## Create Buffer

Use when variability starves or overloads the constraint. Add buffer before the constraint or reserve capacity for interrupts.

## Change Incentives

Use when local metrics reward behavior that hurts throughput. Replace utilization/output metrics with flow, lead time, quality, or value metrics.

## Change Information Flow

Use when people wait because information is hidden. Create dashboards, decision logs, ownership maps, handoff contracts, or alert routing.

## Kill Low-Value Work

Use when the system is overloaded by nonessential demand. Remove meetings, reports, features, projects, checks, or rituals that do not support the system goal.
